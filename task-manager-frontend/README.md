# Task Manager Frontend

Frontend desarrollado con Angular para la gestión de tareas.

## Tecnologías utilizadas

- Angular
- TypeScript
- HTML5
- CSS3

---

## Funcionalidades

- Crear tareas
- Editar tareas
- Eliminar tareas
- Paginación
- Estadísticas básicas
- Diseño responsive
- Toast notifications

---

## Ejecutar proyecto

```bash
npm install
ng serve

Aplicación disponible en:

http://localhost:4200
Arquitectura

El proyecto frontend está organizado utilizando componentes standalone, servicios y separación modular para una mejor mantenibilidad.
